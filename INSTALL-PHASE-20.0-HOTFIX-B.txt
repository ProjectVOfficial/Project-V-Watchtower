PROJECT V WATCHTOWER — PHASE 20.0 HOTFIX B
MULTI-PROVIDER LIVE AIR

1. Close Watchtower.
2. Extract this ZIP.
3. Copy the included src folder into:

   E:\PROJECTS\worldmonitor-2.5.23

4. Choose Replace files in destination.
5. In PowerShell run:

   cd "E:\PROJECTS\worldmonitor-2.5.23"
   npm run typecheck

6. If typecheck is clean:

   npm run desktop:dev

FIRST TEST
----------
1. Open Map 2.0.
2. Set the new provider selector to AUTO · ADSB.LOL.
3. Turn on LIVE AIR or choose AIR.
4. Zoom to level 5 or closer over a populated region.
5. Watch the status beside the provider selector.

Expected:

   LOADING...
   then
   <count> AIRCRAFT · ADSB.LOL

Aircraft should render as colored, heading-rotated airplane silhouettes.

If AUTO cannot reach ADSB.lol it will attempt the existing OpenSky relay when available. If both fail, the status will show AIR OFFLINE; hover the status to see the underlying error.

No new npm dependency is added by this patch.
