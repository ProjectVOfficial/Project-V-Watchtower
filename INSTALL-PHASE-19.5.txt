PROJECT V WATCHTOWER — PHASE 19.5
MISSION PROFILES

Target project:
E:\PROJECTS\worldmonitor-2.5.23

INSTALL
1. Close Watchtower.
2. Extract this ZIP.
3. Copy the included src folder into:
   E:\PROJECTS\worldmonitor-2.5.23
4. Choose Replace files in destination.
5. From PowerShell in the project folder run:
   npm run typecheck
6. If typecheck is clean, launch with:
   npm run desktop:dev

WHAT THIS PHASE ADDS
- V menu section 06: MISSION PROFILES
- Seven operational modes:
  GLOBAL WATCH
  BREAKING NEWS
  OSINT INVESTIGATION
  MILITARY WATCH
  CYBER
  MINIMAL MAP
  CUSTOM
- One-click workspace + layout + Quick Bar configuration
- Active-profile status inside the V drawer
- Mission profile selection persists locally across Watchtower restarts
- Manual workspace/layout/module/Quick Bar changes automatically return the mission state to CUSTOM
- Theme, API keys, alerts, watchlists, cases, and Project V Bridge bindings are not changed by mission profiles
- Ctrl+K mission commands, including "mission global", "mission breaking", "mission osint", "mission military", "mission cyber", and "mission minimal"

PROFILE BASELINES
GLOBAL WATCH
  GLOBAL PULSE + COMMAND layout

BREAKING NEWS
  LIVE OPS + VIDEO WALL layout

OSINT INVESTIGATION
  INTELLIGENCE + ANALYSIS layout

MILITARY WATCH
  LIVE OPS + MAP FOCUS layout

CYBER
  INTELLIGENCE + THREE COLUMN layout

MINIMAL MAP
  WATCHTOWER + MINIMAL layout

CUSTOM
  Preserves the current manual configuration; it does not reset anything.

FIRST TEST
1. Open V and scroll to 06 MISSION PROFILES.
2. Click BREAKING NEWS.
3. Confirm LIVE OPS becomes active, LAYOUT becomes VIDEO WALL, and the Quick Bar changes to the breaking-news command set.
4. Open V again. BREAKING NEWS should show ACTIVE.
5. Click OSINT INVESTIGATION and confirm the desk changes to INTELLIGENCE with ANALYSIS layout.
6. Change one Quick Bar command manually. The mission indicator should change to CUSTOM.
7. Press Ctrl+K, type "mission military", and run MISSION: MILITARY WATCH.
8. Restart Watchtower. MILITARY WATCH should still be active and reapply its operational configuration.
9. Select CUSTOM and confirm the current configuration remains untouched.

PHASE SCOPE
Mission Profiles configure Watchtower's existing workspace, layout, and Quick Bar systems. They do not create new data feeds or alter alert/watchlist/case content. This keeps Phase 19.5 reversible and prepares the mission-state layer for Map 2.0 and later Project V application handoffs.
