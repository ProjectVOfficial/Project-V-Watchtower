PROJECT V WATCHTOWER — PHASE 20.1 AIR OPERATIONS DESK

1. Close Watchtower.
2. Copy the included src folder and vite.config.ts into:
   E:\PROJECTS\worldmonitor-2.5.23
3. Choose Replace files in destination.
4. Run:
   cd "E:\PROJECTS\worldmonitor-2.5.23"
   npm run typecheck
5. If typecheck is clean, run:
   npm run desktop:dev
