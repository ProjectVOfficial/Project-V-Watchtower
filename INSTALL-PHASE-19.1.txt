PROJECT V WATCHTOWER — PHASE 19.1
ADVANCED LAYOUT MANAGER

TARGET WORKING FOLDER:
E:\PROJECTS\worldmonitor-2.5.23

BASELINE REQUIRED:
The Theme + V Drawer patch and UI-2 Theme Propagation patch should already be installed.
This patch was built directly on that state.

INSTALL:
1. Close Project V Watchtower.
2. Stop npm run desktop:dev if it is still running.
3. Extract this ZIP.
4. Copy the included src folder into:
   E:\PROJECTS\worldmonitor-2.5.23
5. Choose "Replace the files in the destination" when Windows asks.
6. In PowerShell run:

   cd "E:\PROJECTS\worldmonitor-2.5.23"
   npm run typecheck

7. If typecheck passes, run:

   npm run desktop:dev

WHAT CHANGED:
- LAYOUT button now opens the Phase 19.1 Advanced Layout Manager.
- Existing top-bar buttons remain in place and keep their original behavior.
- The manager shows the current desk, preset, map width, CORE/CUSTOM state, and DEFAULT state.
- Presets: Command, Map Focus, Analysis, Video Wall, Three Column, Minimal.
- Map width: Full, Command, Compact.
- Current desk actions: Save Now, Auto Arrange, Edit Deck, Duplicate, New Desk, Rename, Set Default, Manage Desks.
- Portability/recovery: Export, Import, Reset Layout.
- Built-in/core desks cannot be renamed directly; duplicate first, then rename the custom copy.
- Layout manager styling follows Watchtower Classic, Project V Shadow, and Midnight themes.
