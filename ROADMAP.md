# Project V // Watchtower Roadmap

This roadmap describes current direction rather than guaranteed delivery dates.

## Repository and upstream foundation

- Maintain Watchtower as an explicit fork of World Monitor
- Keep upstream attribution and AGPL-3.0-only obligations clear
- Integrate upstream fixes deliberately rather than overwriting Project V behavior
- Keep legacy 1.x history and release artifacts preserved separately

## Watchtower 2.0 direction

The next Watchtower line is focused on retaining the strongest Project V workflows while modernizing the underlying workspace and monitoring experience.

Planned areas include:

- customizable desks and movable/resizable panels
- improved command palette and mission presets
- dedicated Video Wall for news, YouTube, and live cameras
- stronger map layers for weather, flights, fires, infrastructure, alerts, and watchlists
- clearer, distinct map symbology
- 2D/3D satellite-style mapping using modern globe/3D tile tooling
- timelines, snapshots, and archival playback
- improved research and investigation workspaces
- optional local assistant integration
- Project V ecosystem interoperability

## Reliability and security

- broader Windows validation
- installer and portable-build regression testing
- backup/recovery validation
- dependency review
- provider-failure handling
- restricted-network testing
- stronger release integrity and signing where practical

## Research and provenance

- stronger source provenance
- better citation/export workflows
- contradiction and timeline analysis
- clearer confidence/uncertainty fields
- integration with Project V Chronicle for deeper archival preservation

## Performance

- reduce unnecessary startup work
- lazy-load heavyweight mapping and analysis components
- measure memory use during long sessions
- optimize large live-data views

No roadmap item is a promise or guaranteed release date.
