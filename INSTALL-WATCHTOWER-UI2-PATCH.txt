PROJECT V // WATCHTOWER
UI-2 THEME PROPAGATION PATCH

Target working folder:
E:\PROJECTS\worldmonitor-2.5.23

PREREQUISITE
This patch assumes the previous "Theme + V Drawer" patch is already installed.

WHAT THIS PASS DOES
- Extends Project V Shadow and Midnight into Modules, Desks, Plugin Control,
  Security Center, Voice Control, Search/Settings surfaces, and layout/editor chrome.
- Extends Shadow/Midnight into standalone Analysis Room, OSINT Desk,
  Assistant Desk, Case/Data workspaces, and Map Operations chrome.
- Leaves semantic danger/error states red, warning states amber, and success states green.
- Adds cross-window theme synchronization through the existing theme preference storage.
- Leaves Watchtower Classic unchanged.

INSTALL
1. Close Project V Watchtower and stop npm run desktop:dev.
2. Extract this ZIP.
3. Copy the included src folder into:
   E:\PROJECTS\worldmonitor-2.5.23
4. Choose "Replace the files in the destination" when Windows asks.
5. Do NOT copy these files into the BACKUP-PRE-THEME folder.

VERIFY
Open PowerShell in E:\PROJECTS\worldmonitor-2.5.23 and run:

  npm run typecheck

If that succeeds, run:

  npm run desktop:dev

TEST CHECKLIST
- Select Project V Shadow from the V drawer.
- Open Plugins: general chrome should be blue; Restricted Sandbox and Uninstall remain red.
- Open Modules, Desks, Security, Voice, Search, API Keys, and Settings.
- Open Analysis Room and OSINT Tools; their normal chrome should follow Shadow.
- Switch to Midnight and verify those surfaces switch as well.
- Switch to Watchtower Classic and verify the original red command-center appearance returns.

ROLLBACK
Restore the three files in this patch from:
E:\PROJECTS\worldmonitor-2.5.23-BACKUP-PRE-THEME-2026-08-12
or from your previous working copy if you want to keep the first Theme + V Drawer pass.
