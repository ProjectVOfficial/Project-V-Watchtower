PROJECT V WATCHTOWER — PHASE 19.3
COMMAND PALETTE

BASE EXPECTED:
Phase 19.2 + Hotfix B working.

INSTALL:
1. Close Watchtower and stop npm run desktop:dev.
2. Copy the included src folder into:
   E:\PROJECTS\worldmonitor-2.5.23
3. Choose Replace files in destination.
4. Run:
   cd "E:\PROJECTS\worldmonitor-2.5.23"
   npm run typecheck
5. If clean, run:
   npm run desktop:dev

WHAT PHASE 19.3 ADDS:
- Ctrl+K command palette available from any Watchtower desk.
- Header SEARCH control becomes COMMAND and opens the palette.
- Search/filter commands by workspace, tool, layout, theme, or system action.
- Arrow Up/Down navigation, Enter to run, Escape to close.
- Commands remain available even if their Quick Bar button is drawer-only.
- Includes Watchtower workspaces, Modules, Plugins, Apps, Camera Wall,
  Analysis Room, OSINT, Alerts, Voice, Security, Comms Wall, Map Command,
  AI Assistant, layout presets, map widths, theme switching, API Keys,
  Settings, and the original intelligence search.

PRIMARY TEST:
1. Press Ctrl+K.
2. Type: camera
3. Confirm OPEN CAMERA WALL is selected.
4. Press Enter and confirm Camera Wall opens.
5. Press Ctrl+K, type: shadow, press Enter, confirm Shadow theme applies.
6. Press Ctrl+K, type: map width compact, press Enter, confirm map width changes.
7. Press Ctrl+K, type: search intelligence, press Enter, confirm the original
   Watchtower intelligence search opens.
8. Press Ctrl+K and Escape, confirm the palette closes.

No backend/Tauri files are changed by this patch.
