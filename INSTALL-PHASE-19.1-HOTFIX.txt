PROJECT V WATCHTOWER — PHASE 19.1 HOTFIX A
Layout Manager placement + close control + status badge clarity

TARGET PROJECT
E:\PROJECTS\worldmonitor-2.5.23

WHAT THIS FIXES
1. Advanced Layout Manager now opens to the RIGHT of the LAYOUT button instead of extending off the left side of the window.
2. Adds a dedicated X close button in the Layout Manager header.
3. Escape closes the Layout Manager and returns focus to the LAYOUT button.
4. CORE / DEFAULT indicators are restyled and relabeled as status indicators (CORE DESK / STARTUP DEFAULT) so they no longer look like clickable buttons.

INSTALL
1. Stop npm run desktop:dev and close Watchtower.
2. Copy the included src folder into:
   E:\PROJECTS\worldmonitor-2.5.23
3. Choose Replace files in destination.
4. Run:
   cd "E:\PROJECTS\worldmonitor-2.5.23"
   npm run typecheck
5. If typecheck passes:
   npm run desktop:dev

TEST
- Click LAYOUT: CUSTOM. The manager should open from the button toward the right.
- Click the X in the manager header; it should close.
- Open it again and press Esc; it should close.
- CORE DESK and STARTUP DEFAULT are informational status labels, not buttons.

NOTE
Phase 19.2 customizable command bar is NOT part of Phase 19.1. It will be the next feature phase after this hotfix is verified.
