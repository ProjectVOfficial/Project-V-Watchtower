PROJECT V // WATCHTOWER
PHASE 20.0 HOTFIX A — LIVE AIRCRAFT DISPLAY

This hotfix addresses the Map 2.0 LIVE AIR "RELAY OFFLINE" problem seen in
development and changes aircraft rendering to a dense ADS-B-style plane view.

INSTALL
1. Close Watchtower.
2. Copy the included src folder into your Watchtower project root.
3. Replace files in destination.
4. Run:
   npm run typecheck
5. If clean:
   npm run desktop:dev

TEST
1. Open Map 2.0.
2. Click AIR or LIVE AIR.
3. Zoom into a populated region above zoom level 3.
4. The status should move from LOADING to an aircraft count.
5. Aircraft should appear as heading-rotated plane silhouettes.
6. Colors represent altitude:
   red/orange = low
   yellow/green = mid-low
   cyan/blue = high
   purple = very high
   gray = ground
   green = watched
   white = selected
7. Click an aircraft to open the inspector.

NOTES
- This uses OpenSky live state vectors. It is intentionally not an embedded
  ADS-B Exchange webpage.
- Coverage and aircraft counts will differ from ADS-B Exchange because the
  providers and receiver networks are different.
- Anonymous OpenSky access is rate/credit limited. The existing Watchtower
  visible-region and refresh throttles remain in place.
