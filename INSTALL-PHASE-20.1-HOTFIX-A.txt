PROJECT V WATCHTOWER — PHASE 20.1 HOTFIX A

1. Close Watchtower / stop `npm run desktop:dev`.
2. Back up your current project folder.
3. Open this ZIP.
4. Drag the `src` folder from the ZIP onto the root of your Project V Watchtower project.
5. Allow Windows to merge folders and replace the matching files.
6. Start Watchtower again with:
      npm run desktop:dev

VERIFY:
- Open MODULES and search `air`.
- AIR OPERATIONS MAP should no longer say DISABLED IN INTERFACE SETTINGS.
- Click AIR OPS on Map 2.0.
- Watchtower may switch to LIVE OPS, but it should scroll to the AIR OPERATIONS MAP module rather than leaving you on only the normal Map 2.0 panel.
- The time-range strip should sit above the Map 2.0 situation deck instead of covering it.
- Drag the MAP 2.0 brand area to reposition the situation deck.
- Double-click that brand area to reset its position.
