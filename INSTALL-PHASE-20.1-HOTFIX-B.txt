PROJECT V WATCHTOWER — PHASE 20.1 HOTFIX B
RESTORE FIXED EDIT DECK CONTROL

1. Stop Watchtower / npm run desktop:dev.
2. Copy the included src folder into the ROOT of the Watchtower project.
3. Merge folders and replace the matching file when prompted.
4. Start Watchtower again with npm run desktop:dev.

EXPECTED RESULT
- EDIT DECK is permanently visible beside the LAYOUT selector.
- It can no longer disappear because of Quick Bar pin/customizer settings.
- Click EDIT DECK to enable panel movement and resizing.
- While active it changes to LOCK DECK.
- Existing saved layout-editing state is preserved.

This hotfix is intended to be installed AFTER Phase 20.1 Hotfix A.
