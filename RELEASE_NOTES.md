# Project V Watchtower 1.0.0

Initial Project V distribution foundation.

- Replaces the prominent World Monitor license card with Project V local-access status and a generated Watchtower access key
- Moves the optional World Monitor credential into Upstream & Compatibility
- Establishes Project V-first data routing and a future self-hosted gateway hook
- Produces Windows NSIS and MSI installers
- Produces a non-installable portable Windows archive
- Adds signed Tauri updater configuration and installed-edition update checks
- Adds portable-edition release discovery
- Generates `latest.json`, `project-v-release.json`, SHA-256 checksums, and a matching source archive
- Adds declarative connector metadata for future reviewed connector-pack updates
- Preserves the existing command deck, AI, Research Library, Case Desk, Data Desk, Map Desk, alerts, communications, Camera Wall, OSINT Desk, Launch Deck, voice tools, and Analysis Room

See `PROJECT_V_PHASE_18.md` and `docs/PROJECT_V_RELEASE_GUIDE.md` before publishing a release.
