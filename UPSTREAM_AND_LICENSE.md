## Corresponding source for binaries

When Project V distributes a Watchtower binary derived from this AGPL-covered fork, the exact corresponding source for that binary must be made available as required by AGPL-3.0-only.

For future releases from this repository, the preferred pattern is:

1. build from a clearly identified commit;
2. tag the exact release source;
3. publish the Windows binary assets;
4. publish checksums;
5. ensure the tagged repository source contains all Project V covered source needed to build that release;
6. include applicable notices and modification information.

If generated files or build inputs needed for corresponding source are not represented by the tag, provide them separately.
